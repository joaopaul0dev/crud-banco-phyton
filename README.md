# Projeto Python - Mini utilitários

Este projeto contém quatro scripts Python simples que demonstram conceitos básicos de entrada de usuário, estruturas de dados e fluxo de controle.

## Arquivos

- `agenda.py`
  - Um gerenciador de contatos simples.
  - Permite adicionar contatos com um ou mais números de telefone.
  - Exibe todos os contatos inseridos ao final.

- `banco.py`
  - Um pequeno sistema bancário de linha de comando.
  - Permite cadastrar contas, depositar, sacar, consultar e excluir contas individualmente ou todas de uma vez.
  - Inclui validação básica de entrada do usuário.

- `forca2.py`
  - Jogo da forca em modo texto.
  - O computador escolhe uma palavra aleatória de uma lista embutida.
  - O jogador deve adivinhar letras antes de ficar sem tentativas.

- `listaP.py`
  - Cadastro de pessoas com nome e idade.
  - Ordena e exibe a lista de pessoas por idade.

## Requisitos

- Python 3.x

## Como executar

Abra um terminal na pasta do projeto e execute um dos scripts:

```bash
python3 agenda.py
python3 banco.py
python3 forca2.py
python3 listaP.py
```

## Observações

- Os dados são mantidos apenas em memória durante a execução de cada script.
- Não há persistência em arquivos ou banco de dados.
- Os scripts foram criados para fins de prática e aprendizado de Python.
